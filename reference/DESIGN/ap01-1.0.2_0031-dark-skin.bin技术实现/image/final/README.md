# AP01 黑色主题最终视觉资产

本目录收录用户逐页确认的最终视觉稿，共 56 个 PNG/GIF 文件。`manifest.csv` 记录每个文件的页面用途、原始来源、格式、尺寸、帧数、字节数和 SHA-256。

所有视觉文件已验证为 320×240。图中的功率、电压、电流、日期、天气、联网和开关值只用于排版；固件实现必须继续绑定原厂实时字段。

实时页面不能直接用这些完整画面覆盖。原厂功率、时间、日期、天气、设置和端口页面由运行时控件与局部资源共同生成，具体实现以 `knowledge/AP01-官方固件分析/1.0.2_0031全页面视觉资源映射.md` 为准。

执行 Loader 安装、OTA 或刷写前，仍须单独取得用户明确确认。
