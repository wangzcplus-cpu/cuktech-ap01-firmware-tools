# AP01 全页面深色换皮视觉稿

## 当前状态

全页面视觉稿已经逐页确认。实现基准统一位于 [`final`](final/) 目录：

- 56 个最终 PNG/GIF 视觉文件；
- 全部为 320×240；
- `final/manifest.csv` 记录来源、格式、尺寸、帧数、字节数和 SHA-256；
- `final/README.md` 记录使用边界。

本目录根部的 `00` 至 `41`、`emil-v2` 和其他早期文件保留为设计过程与原画对照，不作为固件实现输入。后续页面 `42` 至 `90` 的最终版本也已整理进 `final`，不再从分散路径读取。

视觉稿中的功率、电压、电流、日期、天气、联网和开关值只用于排版。实时页面由原厂运行时控件与局部资源生成，固件实现必须继续使用原厂动态字段；不得将完整视觉稿作为实时页面静态覆盖层。

逐页原厂函数、资源和停止条件见 [`1.0.2_0031全页面视觉资源映射.md`](../../../../../knowledge/AP01-官方固件分析/1.0.2_0031全页面视觉资源映射.md)。

Loader、OTA 或刷写不属于视觉确认范围，执行前必须单独取得用户明确确认。
