# AP01 `1.0.2_0031` 全页面视觉资源映射

## 1. 文档状态与边界

本映射对应原厂型号 `njcuk.enstor.ap01`、固件 `1.0.2_0031`。原厂固件样本：

- 文件：`artifacts/firmware/original/ap01-1.0.2_0031.bin`
- 大小：`6,804,520` 字节
- SHA-256：`8a721fc8ef25458d415b2460e4a251e0503a82f7743fdff85b12612190e5c1cb`
- 文件偏移到运行地址：`运行地址 = 文件偏移 + 0x9ffff000`

本文只确定视觉实现的归属、证据和停止条件。它不授权构建、安装 Loader、OTA 或刷写设备。

证据等级：

- **A**：原厂代码地址、资源描述引用和解码内容互相印证。
- **B**：原厂代码/文档与解码内容两项印证，但尚未完成真机逐控件核对。
- **C**：只确认页面存在或视觉内容，修改地址仍需继续定位；不得据此写固件。

## 3. 资源描述结构与引用扫描

固件中确认 199 个可解码 PNG 和 10 个可解码 GIF。PNG/GIF 数据前存在 LVGL 资源描述对象。对本版本的直接引用扫描表明，绝大多数图像在代码中引用的是：

`资源数据运行地址 - 28`

原先只按 `-16` 搜索会漏掉大多数引用。修正后找到 193 个 `LUI + ADDI` 形式的资源描述直接引用。完整结果保存在：

- `ap01_firmware_analysis/assets.csv`
- `ap01_firmware_analysis/asset-xrefs.csv`
- `ap01_firmware_analysis/png-contact-sheet.png`
- `ap01_firmware_analysis/gif-contact-sheet.png`

资源描述大小仍须按每项旧字节和解码结果校验，禁止把 `-28` 作为跨版本常量。

### 5.2 一级页面工厂的真实分支边界

`0xa00b2600` 先创建九个一级直接子对象，再按页面进入不同创建分支。此前按相近地址等距切分会把功率页后半段错误归入时间页。以分派跳转目标和共享收尾路径交叉确认后的边界为：功率 `0xa00b2860..0xa00b30ce`、时间 `0xa00b30ce..0xa00b396c`、日期 `0xa00b396c..0xa00b3b12`、天气 `0xa00b3b12..0xa00b3f02`、设置 `0xa00b3f02..0xa00b402c`、萌宠从 `0xa00b402c` 开始。逐对象表和后续补丁只允许使用这些分支边界。

### 5.3 动画时序、容量和资源换位结论

- 原厂萌宠候选 GIF 为 320×240、14 至 41 帧、每帧 120 至 150 毫秒、无限循环。原厂 `0x1f80ac` 资源无损优化后为 324,886 字节，继续提供 `0x2475d0` 开始的 60,934 字节已验证程序区。
- 新萌宠为 24 帧、每帧 90 毫秒、无限循环；固定工具无损优化后 374,361 字节，逐帧 RGBA 一致。它不能与 60,934 字节程序同时放入原萌宠槽，因此改放入 `0x57e830` 的 502,081 字节槽。
- 新屏保为 48 帧、每帧 100 毫秒、无限循环。72 色固定调色板版本为 404,255 字节，保留全部帧和 4.8 秒周期，可放入 `0x5f9190` 的 414,606 字节槽，余 10,351 字节。
- 原功率屏保的资源引用从 `0xa057d814` 改为 `0xa05f8174`；萌宠页引用从 `0xa01f7090` 改为 `0xa057d814`。这样时间屏保和功率屏保共用新屏保，新萌宠独占原功率屏保槽，已验证程序区不再与新萌宠冲突。

### 5.4 对象坐标与尺寸字段

原厂固件中的直接指令证明当前版本对象坐标字段为四个连续 32 位值：`+20` 是 `x1`，`+24` 是 `y1`，`+28` 是 `x2`，`+32` 是 `y2`。`0xa00c0264` 的宽度函数读取 `+28` 和 `+20` 后计算 `x2 - x1 + 1`；`0xa00c02bc` 的高度函数读取 `+32` 和 `+24` 后计算 `y2 - y1 + 1`。`0xa00c01e4` 的纵坐标函数读取 `+24`，`0xa0088f82..0xa0088fb4` 的内联横坐标路径读取 `+20`，两处都同时处理父对象与滚动偏移。

只读观察版本不调用未确认入口，也不推测结构；它直接读取上述已证实的绝对坐标字段，并调用已确认的 `0xa00c5d84` 和 `0xa00c5fe4` 遍历子对象。对象起始处的类指针以及 `+8`、`+12`、`+16` 的标志、样式指针和用户数据指针只作为原始状态值记录，不进行写入。
